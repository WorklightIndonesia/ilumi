# ilumi
After cloning the repository, you can do:
1. cd ilumi
2. npm install
3. npm run build
3. npm run build
4. php artisan serve

If you are having trouble regarding SSL when using laravel, make sure add an exception URL to your Antivirust. The followinga tutorial can be watched in here:
